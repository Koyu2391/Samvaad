# Samvaad Financial RAG API — `backend/main.py`

> **App:** `FastAPI(title="Samvaad Financial RAG API", description="Multi-user financial RAG backend")`
> **Run:** `uvicorn main:app --host 0.0.0.0 --port 8002` (`main.py:1400-1401`)
> **Base URL:** `http://localhost:8002`
> **Interactive docs:** `GET /docs`, `GET /openapi.json` (auto-generated by FastAPI)

## 1. Conventions

| Item | Detail |
|---|---|
| Auth | `Authorization: Bearer <access_token>` on all routes except `GET /api/health`. Implemented via `core.security.get_current_user` (`Depends`). |
| Roles | `viewer` = read-only (`403` on upload/delete). `analyst` / `admin` = full. |
| Session model | In-memory `_sessions: dict[str, SessionState]` (`main.py:163`). Key = `user_{user.id}` or `{sid}_{conv_id}`. `SessionState` holds PGVector retriever, BM25, `HybridRetriever`, reranker, `ImageStore`, `messages`, `selected_model`. |
| Storage | `backend/uploads/<sid>/`, `backend/convs/<conv_id>/`, PGVector `document_chunks` (scoped by session/conv), `backend/conversations/`. |
| CORS | `config.CORS_ORIGINS` default `http://localhost:5174,5173,3000` (`config.py:65-68`). |
| DB | SQLAlchemy `Session` via `database.get_db`. Redis cache for `GET /api/conversations` and `GET /api/status`. |
| Errors | Standard FastAPI: `400` bad file type, `401/403` auth/role, `404` conv/doc/image not found. |

## 5. Documents

  All indexing uses Phase-2 parser `financial_parse()` (Docling + OCR fallback) + `chunk_for_financial_rag()`, PGVector + `BM25Okapi`, full-page + XREF image indexing with OpenCLIP (`_build_index`, `_build_image_index`).

### `POST /api/documents/upload` — sync

Auth (non-viewer). `multipart/form-data`: `files: List[UploadFile] (File(...))`, `conversation_id: str = Form(None)` (`main.py:816`).
Only `.pdf` accepted (else `400`). Saves to session upload dir, upserts `Document(status="processing")`, calls `_build_index(session)`, then marks `indexed` + `indexed_at`, invalidates caches.
Response (from `_build_index`):

```json
{"message":"Indexed 42 chunks from 1 files.","engine_initialized":true,"files":["report.pdf"],"chunks":42,"tables":3,"images_indexed":5,"used_ocr":false,"used_docling":true}
```

Or fast path: `{"message":"Loaded existing index (1 files).",...}`.

```bash
curl -X POST http://localhost:8002/api/documents/upload \
 -H "Authorization: Bearer $TOK" \
 -F "files=@report.pdf" -F "conversation_id=$CONV"
```

### `DELETE /api/documents/{filename}`

Auth (non-viewer). Query: `?conversation_id=...` (`main.py:882`). Removes file (rename to `.deleted` on `PermissionError`), deletes DB row, rebuilds index.
Response: same `_build_index` dict.

### `GET /api/documents`

Auth. Query: `?conversation_id=...` optional. Org-scoped, `uploaded_at DESC` (`main.py:921`).

```json
{"files":["a.pdf"],"documents":[{"id":"...","filename":"a.pdf","conversation_id":"...","status":"indexed","uploaded_by":"...","uploaded_at":"...","size_bytes":123,"chunks_count":0,"error_message":null}]}
```

### `POST /api/documents/upload/async` — background (Celery)

Auth (non-viewer). `multipart/form-data`: `files` only (no `conversation_id` — note: uses `get_session(sid, user.organization_id)` at `main.py:970`, likely a bug). Accepts `.pdf/.txt/.eml/.md`. Saves file, creates `Document(status="pending")`, dispatches `ingest_document_task.delay(document_id,file_path,organization_id,session_id)`.
Response:

```json
{"queued":[{"document_id":"...","filename":"a.pdf","task_id":"celery-uuid"}],"message":"1 document(s) queued for background indexing."}
```

### `GET /api/documents/tasks/{task_id}`

Auth. Poll Celery status via `tasks.ingest.get_task_status` (`main.py:1040`). Returns task state (`PENDING/PROGRESS/SUCCESS/FAILURE` + meta).

## 6. Chat (RAG + Multimodal)

### `POST /api/chat`

Auth. Body: `ChatRequest` JSON (`main.py:1058`).

Pipeline:

1. `get_session(sid, conversation_id)`, set `selected_model/use_reranker`.
2. Re-init retriever on model change (`_init_query_engine`: `k = max(DEFAULT_K=8, min(K_PER_FILE=6 * files, MAX_K=20))`, `HybridRetriever` if BM25 available).
3. Append user msg, `update_memory(sid, prompt)` (non-fatal).
4. Auto-build index if `query_engine is None` but files exist on disk.
5. `_invoke_graph_pipeline()` → `core.graph.run_query(...)` with chat history (last 6), user memory → `(answer, sources, context)`.
6. Image retrieval: `embedder.embed_text(prompt)` → `ImageStore.search(k=max(IMAGE_TOP_K*4,8))`, filter `score<0.18`, top `IMAGE_TOP_K=3` (fallback to top-1). If images + text context → re-answer with `LlamaCppServerLLM.chat_with_images()` (images resized to max 800px, base64 PNG).
7. Persist `Conversation` (create/retitle `New Conversation` → `prompt[:80]`) + `DBMessage(user)` + `DBMessage(assistant, sources, image_sources)`.

Request:

```json
{"prompt":"What was Q3 revenue?","model":"default","use_reranker":true,"conversation_id":"..."}
```

Response:

```json
{
  "response":"...",
  "sources":[{"file":"...","page":2,"score":0.91,"content":"..."}],
  "image_sources":[{"file":"...","page":1,"img_id":"doc_page1_full","score":0.32,"caption":"...","ocr_text":"...","type":"figure","is_image":true}],
  "conversation_id":"...",
  "messages":[{"role":"user","content":"..."},{"role":"assistant","content":"..."}]
}
```

### `POST /api/chat/clear`

Auth. Form: `conversation_id: str = Form(None)` (`main.py:1267`). Clears in-memory `messages` only.
`{"message":"Chat cleared."}`

### `GET /api/chat/history`

## 8. Visual-query heuristics (internal, `main.py:192-237`)

- `_is_visual_query()`: regex for `show/display image|figure|chart|graph|diagram|flowchart` etc.; returns `False` for any `table` query.
- `_requested_visual_type()`: `"table"` if `table` in query else `"figure"` if visual term.
- `_source_pages_from_last_sources()`: biases image search to pages cited in text sources.

These drive `preferred_type` / `preferred_pages` passed to `ImageStore.search()` in `/api/chat`.
